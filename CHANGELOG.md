# Changelog

## [1.1.0] - 2026-09-14

- Added bounded GitHub route status: `Complete`, `Partial`, and `Unavailable`.
- Added returned-count reporting and `unknown` markers for totals or metadata that a backend cannot verify.
- Added component-level reuse for demo, starter, and toolkit repositories.
- Added explicit `not runtime-verified` evidence labeling.
- Added separate license checks for code, assets, fonts, audio, data, and dependencies.
- Added composite product/candidate decisions such as `Build` overall plus `Adapt` or `Reference` for individual candidates.
- Added delegated-decision handoff so an explicit user choice does not trigger a redundant confirmation.
- Clarified bounded fallback behavior and preserved the platform-neutral, zero-dependency package.

## [1.0.0] - 2026-09-11

- Initial public release with bounded GitHub exploration, candidate comparison, safety boundaries, and cross-agent installation guidance.
